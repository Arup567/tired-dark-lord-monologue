# The Tired Dark Lord

A 100-word villain monologue, written for the make.fun bounty
"The Tired Dark Lord: A 100-Word Villain Monologue".

`main.ts` writes the monologue to `/output/entry.txt` (UTF-8, within the gate's
600-character cap). The villain is a tired one: the weariness shows in the
pauses, the deflections and the small logistics of his scheme, never in a
stated feeling.

Run it with Node 22:

```
node main.ts
```
