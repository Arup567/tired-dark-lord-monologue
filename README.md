# The Tired Dark Lord — a 100-word villain monologue

An entry for the make.fun bounty **"The Tired Dark Lord: A 100-Word Villain Monologue"**: a fantasy villain
who is secretly just very tired, with the weariness carried by the voice and the small deflections rather than
stated outright. The judge reads entries two at a time and picks the one that would play best in a game.

## What it does

`main.ts` writes one monologue to `/output/entry.txt` (UTF-8, 97 words / 492 characters, inside the bounty's
600-character gate). It is a plain Node 22 program: no dependencies, no network, nothing read from outside the
repository.

## Run it

```
node main.ts
```
